# BASWC-style Static Template (GitHub Pages Ready)

이 저장소는 **정적(HTML/CSS/JS) 템플릿**입니다.  
`index.html`을 GitHub Pages로 배포하면 바로 동작합니다.

## 배포 방법 (GitHub Pages)
1. 이 저장소에 파일 업로드 (index.html, assets/)
2. GitHub → **Settings** → **Pages**
3. Source: **Deploy from a branch**
4. Branch: **main** / Folder: **/(root)** → Save
5. 1~2분 후 제공된 주소로 접속

## 수정 포인트
- `index.html`: 문구/메뉴/연락처/링크 수정
- `assets/style.css`: 색상/레이아웃/폰트 크기
- `assets/app.js`: 배너 슬라이더/모바일 메뉴 동작

> 이미지들은 예시로 Unsplash 외부 링크를 사용합니다.  
> 실제 운영 시에는 `assets/img/`에 업로드해 교체하는 것을 권장합니다.
